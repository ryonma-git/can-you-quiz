# 先生くじ ＆ Can you ...? ワークシート

小学5年 外国語「Can you ...? インタビュー → Mystery Teacher Quiz」用の教材です。

```
README.md
index.html      公開ページの入口（app/ へ移動するだけ）
app/            先生くじWebアプリ
  config.js     ← クラス・班数・A/B/C配分表の設定
data/
  teachers.sample.csv  先生データのひな形（仮名）
  teachers.csv         本物の先生データ（※GitHubには上げない）
worksheets/     ロイロノート用カード（PNG と SVG）
tools/ tests/   作り直し・動作確認用（ふだんは不要）
```

> **個人情報について**：本物の先生名簿 `data/teachers.csv` は `.gitignore` で GitHub に上がらないようにしています。
> 公開ページには先生名は含まれず、先生データは iPad の中のファイルから読み込みます。

---

## 1. 起動方法

### iPad（公開ページ）
1. Safari で公開ページ（GitHub Pages の URL）を開く。
2. 準備画面の **「teachers.csv を選ぶ」** → 「ファイル」アプリから teachers.csv を選ぶ。
3. 班数を確認して **「割当を作成」**。
4. **「授業を始める」** でクラスを押すと、くじの画面になります。

※ Safari の **プライベートブラウズでは使わないでください**（タブを閉じると結果が消えます）。
※ 毎回同じ iPad・同じ Safari で開いてください（結果はその iPad の中に保存されます）。

### Mac / PC
`app/index.html` をダブルクリック → 上と同じ手順。

### 操作メモ
- くじ画面左上の小さな「準備画面へ」で準備画面に戻れます。
- キーボードがあれば Enter / スペース で「くじを引く」、← → で班の移動もできます。

## 2. teachers.csv の場所・形式

`data/teachers.csv`（ひな形は `data/teachers.sample.csv`）。1行目は `name,category` にします。

```
name,category
山田先生,A
田中先生,A
佐藤先生,B
鈴木先生,C
```

- 名前はくじ画面にそのまま表示されます（「山田先生」と書けば「山田先生！」と出ます）。
- 保存するときの文字コードは **UTF-8**（Excel なら「CSV UTF-8」）。
- 空行や前後の空白があっても大丈夫です。1行目が `name,rank` や `name,group` でも読めます。

## 3. 先生名の変更
`teachers.csv` の名前を書き換えて保存 → 準備画面で選び直す。

## 4. カテゴリ（A/B/C）の変更
`teachers.csv` の `,A` `,B` `,C` を書き換える。カテゴリは「5年生との接点の多さ」の目安で、くじ画面・一覧には表示されません。

| カテゴリ | 目安 |
|---|---|
| A | 5年生と接する機会が多く、多くの児童がよく知っている先生 |
| B | 児童がある程度知っている先生 |
| C | 児童は知っているが、ふだん接する機会は少なめの先生 |

## 5. 新しい先生の追加
`teachers.csv` の最後に1行追加（例：`高橋先生,B`）。

## 6. 先生の削除
`teachers.csv` からその行を消す。CSV にいる先生だけがくじに出ます。

## 7. 班数の設定
準備画面の「クラス設定」で各クラスの班数（6〜10）を入力 → 「割当を作成」。
割当を作ったあとに班数を変えたときは、もう一度「割当を作成」を押してください。

## 8. A/B/C配分表の変更場所
`app/config.js` の `categoryTable`（班数ごとに A・B・C から何人選ぶか）。

```js
9:  { A: 6, B: 2, C: 1 },
```

A+B+C の合計が班数と同じになるようにしてください。

## 9. 抽選結果の保存・リセット

- **自動保存**：割当・くじ済みの班・表示中の位置は、操作のたびに iPad の中に自動保存されます。再読み込みやタブを閉じても消えません。くじは押した瞬間に保存されます。
- **保存ファイル（ふっかつ用）**：準備画面の「保存ファイルを作る」で、途中経過（先生データを含む）を `.json` ファイルに保存できます。万一結果が消えても「保存ファイルから元に戻す」で復元できます。授業の終わりごとに作っておくと安心です。
- **結果一覧**：準備画面の「結果一覧を見る」で3クラスの結果を1画面に表示します（スクリーンショット用）。くじを引き終わっていなくても表示でき、まだ引いていない班には「くじ前」と出ます（先生は割当作成時に決まっています）。
- **全リセット**：準備画面の一番下 → 確認で OK。すべての抽選結果が消えます。
- 割当だけ作り直したいときは「割当を作成」をもう一度押す（確認が出ます）。

## 10. ロイロノート用カード

`worksheets/` の PNG をロイロノートに取り込んで配布してください（1600×1200）。

| ファイル | 内容 |
|---|---|
| `card-01-question-builder.png` | 質問を考えよう（日本語 → 英語 → Can you ...?） |
| `card-02-interview.png` | Interview（Q1〜Q4、Yes / No に○） |
| `card-03-quiz-maker.png` | Mystery Teacher Quiz（He / She can / can't） |

### 準備画面に出る表示

| 表示 | 意味・直し方 |
|---|---|
| ○行目：カテゴリ「D」は使えません | A・B・C のどれかにする |
| ○行目：先生の名前が空欄です | 名前を書くか、その行を消す |
| ○行目：「○○先生」が重複しています | 同じ名前を1つにする |
| （黄色）Aカテゴリの先生が3人足りません → Bカテゴリの先生3人で代わりに… | 警告のみ。そのまま作成できます。足りない分は近いカテゴリ（A↔B↔C）の先生で補い、各クラスに均等に振り分けます |
| 先生の人数が合計○人足りません | 先生を増やすか班数を減らす（同じ先生を2回使わないため作成できません） |
| 文字化けしています | teachers.csv を UTF-8 で保存し直す |
